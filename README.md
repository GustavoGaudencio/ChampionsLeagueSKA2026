# Champions League SKA 2026 — Site atualizado

## Como abrir
Abra `index.html` no navegador, mantendo as pastas `css`, `js` e `images` junto a ele. O arquivo `Champions League SKA.html` também funciona como versão única do HTML, mas usa as imagens da pasta `images`.

## Como editar
- **index.html**: estrutura, textos, datas, links e regras.
- **css/style.css**: cores, aparência, posições e tamanhos.
- **js/script.js**: funcionamento do menu mobile.
- **images/**: logotipos e imagem institucional fornecidos pela organização.
